# user-client/AGENTS.md

本文件只记录 C 端商城的项目级约束；完整规则（目录、命名、路由、HTTP、认证、状态、TypeScript、验证、静态值治理）见 [前端开发规范](../docs/10-实战产品蓝图/前端开发规范.md)。

## 1. 当前边界

- 实践顺序、解锁条件和完成状态只以 [实践计划与进度](../docs/10-实战产品蓝图/实践计划/README.md) 为准。
- 未经计划明确解锁，不创建 Mock 业务、页面或接口调用。

## 2. C 端特有约束

- 商城页面优先清晰、顺畅、可转化。
- 商品列表、详情、购物车、下单流程必须有明确状态边界。

## 3. 验证

前端通用验证命令见规范第 12 节。涉及路由、登录、购物车、下单、布局时，必须浏览器验证关键路径和移动端布局。
